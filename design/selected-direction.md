# 已选视觉方向：U03 + I01

用户于 2026-10-27 确认「我的偏好 U03 + I01」。此文件是后续 UI 实现的视觉基准。

## 布局：U03 周历与日程

- 首页上部为七日周历，星期、日期、少量事项标记清楚对齐。默认选择今天，支持选择日期和回到今天。
- 周历下方呈现日程，全天事项优先、定时事项按时间排列；保留逾期、无时间和已完成的功能入口与明确状态。
- 保留“全部待办”和设置入口。添加仍使用快速添加 Sheet；完整日期选择和编辑吸收 U03 右侧界面的月历及表单排布。
- 平整清单、细分隔线和适度留白构成主体。避免添加无关的仪表盘、统计、项目或标签功能。
- 周历是在手机宽度内的真实交互控件，需要验证七列日期的触控尺寸和大字号布局，不照搬图片像素尺寸。

## 图标：I01 极简细线

- 界面采用统一细线、轻圆端点、清楚的负空间；在 24dp 下保持辨识度，并提供至少 48dp 的触控范围。
- 同时用 I01 作为应用图标的美术方向，保留笔记本与勾选意象。启动器图标、深浅色和单色版本按平台需要制作。
- 生成图仅供风格参考。界面图标使用 Compose `ImageVector` 等可控资产制作，不能把整张风格板当作图标资源。

## 排版与色彩

- 基础主题采用 U03 的暖白、炭黑和少量陶土色；动态取色和深色模式保留同样的视觉层级。
- 标题有书卷感，正文克制清晰；使用中文界面验证实际观感，不直接照用图中英文排版。
- 用户后续确认采用相近的开源字体，覆盖原系统字体约束：英文 Source Serif 4 / Source Sans 3，中文思源宋体，离线内置并保留 SIL OFL 1.1 许可证；不宣称使用 Claude 的专有字体。Android 8/9 采用思源宋体自带拉丁字形兼容回退。
- 默认使用暖色主题；动态取色仍可在设置中启用，已有明确设置不被覆盖。
- 0.4.0 根据用户追加要求开放 5 套预设与自定义强调色，并增加英文界面；保持 U03 的暖色纸面和版式层级。未完成的全天事项前方留空，与定时事项的勾选框／标题对齐；0.4.1 按用户反馈取消已完成事项的时间留白。

## 实现边界

- 用户已选定视觉方向，无需再次确认相同选项。
- 生成稿中的英文、日历年份、事项数量、遗漏字段等不属于功能规格。日期按设备当前时间和时区计算，功能以实施规格及已确认决策为准。
- 功能完整、可靠提醒、可读性、无障碍和流畅体验优先；不能为了细线或留白削弱状态可辨性。
- 按用户要求清理探索文件，`design/` 保留已选 U03、I01 原图、本设计基准、`selection.json` 及实现所需字体来源记录；未选候选、对比册和生成记录已删除。
